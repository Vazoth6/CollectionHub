# CollectionHub

## Desenvolvimento Web 2025/2026

### Descrição

O CollectionHub é uma aplicação web desenvolvida no âmbito da unidade curricular de Desenvolvimento Web da Licenciatura em Engenharia Informática.

A aplicação permite aos utilizadores gerir coleções de itens, organizando-os por categorias e registando transações associadas aos mesmos.

O projeto foi desenvolvido utilizando ASP.NET Core Razor Pages para a interface web e ASP.NET Core MVC para a API, cumprindo os requisitos definidos no enunciado da unidade curricular.
